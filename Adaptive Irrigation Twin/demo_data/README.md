# Demo data pack

Use this dataset to check the local app's profile entry, CSV imports, season coverage, scenario list, and AquaCrop comparison viewer. It is for software demonstration only.

## What's real and what's synthetic

- `weather_demo.csv` contains the daily Tmin, Tmax, rain, and ETo from the historical Patancheru example included with AquaCrop. Every row is marked `seasonal` so the app does not present it as current observed weather.
- `observations_demo.csv` contains 10 invented sensor records. Each row is explicitly flagged as synthetic in `notes`; these are not field measurements.
- `field_setup_and_scenarios.json` gives profile values and the five irrigation scenarios. The app has no JSON import for profile/scenarios yet, so enter those values in the corresponding forms.
- `scenario_outputs/` contains the five daily and seasonal outputs generated by actual AquaCrop 7.3 runs, each with one 0/5/10/15/20 mm event on 1996-10-15.

## Load into the app

1. Open `index.html`. Use the values under `profile` in `field_setup_and_scenarios.json` to fill the Field profile, then save it.
2. Import `observations_demo.csv` in Field observation input. The table should show 10 synthetic records.
3. Import `weather_demo.csv` under Daily weather timeline. Coverage should read complete: 132 / 132 days, July 1 to November 9, 1996.
4. Add the five rows from the JSON `scenarios` array in the scenario form. Import `scenario_outputs/scenario_summary.csv`, keep the default limits (5% seasonal transpiration deficit, 100 mm water cap, and 95% minimum yield retained), then choose **Evaluate irrigation advice**. This demo selects the 0 mm event because all runs have the same yield and modeled deficit.
5. Open `visualization.html`, import the five daily CSVs from `scenario_outputs/`, and select two scenario names to compare. Repeat with other pairs.

The example's full-season rainfall is high enough that all five runs have the same final yield. Root-zone water differs on the irrigation event day. The evaluator's choice illustrates its minimum-water ranking rule; it is not a real field recommendation.
